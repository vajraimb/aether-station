# Cislunar flight visualization

Patched-conic Earth → Moon transfer, then a 100 km lunar orbit. Speeds and
altitudes in the HUD are physical. The 3D layout uses an orrery scale so Earth,
Moon and the probe are all readable at once. This is **not** the frozen AETHER
attitude plant.

The app root `/` is this view. Station lab is at `/station`.

- Drag to orbit, scroll / pinch to zoom.
- System / Earth / Moon / Craft snap the camera target; zoom stays user-controlled.
- Inset shows the probe with body axes (radial / normal / prograde).
